# 培养建议录入规范（P3）

用户对照屑夫蒂一图流校对录入 character_meta.json 时使用的模板。

---

## 📋 指令模板

| 用途 | 指令 |
|---|---|
| **查询培养建议**（推荐） | `/养成 <角色名>` |
| 查询角色卡 | `/角色 <角色名>` |
| 查询（角色名含特殊字符时） | `/wiki <关键词>` |

---

## 📸 截图模板

每张角色卡的截图需包含该角色的**完整卡片**（立绘 + 数据列），建议：

```
┌─────────────────────────────────┐
│ [强度评级]                       │  ← 可选顶部强度标签
│  ┌───┐ 装备：xxx                │
│  │立绘│ 词条：xxx                │
│  │   │ 备注：xxx（可选）          │
│  └───┘ 技能：xxx                │
│        魔方：xxx                  │
│        收藏品：xxx                │
└─────────────────────────────────┘
```

- **红框**：在主识别区域加红框标记（便于识别范围）
- **横向**：左立绘 + 右数据列
- **纵向**：强度（顶）→ 装备 → 词条 → 备注 → 技能 → 魔方 → 收藏品

---

## ✍️ 数据文本模板

每个角色用以下**7 行固定字段**（顺序、字段名严格一致）：

```
强度：<评级>          # 例：3.5红级别 / 3红级 / 4红级别 / T0
装备：<装备>          # 例：4T10，头手甲升级 / 无所谓
词条：<词条>          # 例：4优越、4攻击、1装弹
备注：<备注>          # 可选，例：想12词条可以继续洗双爆
技能：<技能加点>      # 例：10/10/10 / 7+/4/7+
魔方：<魔方>          # 例：战术巨熊 / 战术/遗迹巨熊（子弹多随意）
收藏品：<收藏品>      # 例：SR15级 / SRO+级
```

### 字段规则

| 字段 | 必填 | 说明 |
|---|---|---|
| 强度 | ✅ | 等级（X.X红级别 / X红级 / T0/T1 等） |
| 装备 | ✅ | 装备名 |
| 词条 | ✅ | 推荐词条组合 |
| 备注 | ⚪ 可选 | 用法提醒、配队、特殊说明等（多行用 `；` 分隔） |
| 技能 | ✅ | 技能1/技能2/爆裂 加点（用 `/` 分隔） |
| 魔方 | ✅ | 推荐魔方 |
| 收藏品 | ✅ | 收藏品等级 |

---

## 🔄 录入流程

1. **截图 + 文本**：每次校对一个角色，发原图+7 行文本（参考上方模板）
2. **AI 处理**：OCR 提取 + 写入 `character_meta.json`（重跑 `tools/build_character_meta.py`）
3. **核对**：群里发 `/养成 <角色名>` 看输出，原图区块截图会在调试期一并发送方便对照
4. **修正**：OCR 误读的字段对照 `data/meta_crops/<角色名>.png` 修正，告诉我具体字段值即可

---

## 🛠 已知 OCR 误读（核对时关注）

- 词条字段 OCR 容易截断（如"4优越、4攻击、1装弹"→只识别"4优越、"）
- 数量词 OCR 误差大（如"亿"=优越、"1装弹"→"1装"）
- 技能值分行合并可能出错（如"10/10/10"分两行）
- 角色名锚点误归：场景标题（电击代码主）可能被识别为角色备注

---

## 📁 数据位置

- `data/character_meta.json`：角色培养数据（36 角色）
- `data/meta_crops/<角色名>.png`：原图区块截图（调试期方便核对）
- `tools/build_character_meta.py`：重新跑提取脚本（慎用，会覆盖手工修正，除非已加入 MANUAL_FIXES）
